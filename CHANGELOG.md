# Changelog

All notable changes to Aervellum are documented here.

## [0.1.0] - 2026-08-02

### Added

- Fully local speech-to-text through `whisper.cpp`.
- Entry, Diary, and Poem layouts on a textured paper interface.
- Markdown-backed archive with paging, touch swipes, editing, autosave, and
  recoverable deletion.
- Optional private phone access through Tailscale Serve.
- Runtime setup paths for Windows Vulkan, NVIDIA CUDA, CPU-only systems, and
  macOS Metal.
- Early native iPhone companion source using SwiftUI and WhisperKit/Core ML.

### Notes

- Models, local runtimes, recordings, transcripts, and diary entries are not
  distributed with the source release.
- Broad hardware and operating-system support is ongoing and may be buggy.
