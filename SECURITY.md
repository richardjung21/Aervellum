# Security policy

## Supported versions

Aervellum is early-stage software. Security fixes are applied to the latest
published version and the `main` branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature from the
repository's **Security** tab. Do not include private notes, recordings,
credentials, Tailscale addresses, or other personal information in a public
issue.

When reporting, include the affected version, operating system, reproduction
steps, and the likely privacy impact. Redact local paths and sample data unless
they are essential to reproduce the issue.
